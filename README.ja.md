# echizen-city-web

本リポジトリは、市民および観光客向けの情報を提供する、架空の越前市公式ウェブサイト用の静的HTMLテンプレートを提供します。テンプレートはBootstrap 4で構築されており、自治体ポータルサイトの構成例を示しています。

## デモ

このプロジェクトには2つの異なるテンプレートデザインが含まれています:

- **Demo 1:** [https://code4fukui.github.io/echizen-city-web/static/demo1/](https://code4fukui.github.io/echizen-city-web/static/demo1/)
- **Demo 2:** [https://code4fukui.github.io/echizen-city-web/static/demo2/](https://code4fukui.github.io/echizen-city-web/static/demo2/)

Demo 1は、目を引くヒーロー画像、最新ニュース、サービスカテゴリを備えたクリーンなレイアウトが特徴です。Demo 2は、主要なライフイベントに焦点を当てた、別のアプローチのナビゲーション構造を提供します。

## 特徴

- **2つのレスポンシブテンプレート**: Bootstrap 4フレームワークで構築された、2つの異なるモバイルフレンドリーなデザイン（`demo1`および`demo2`）が含まれています。
- **動的なコンテンツ生成**: `demo1`のページは、Denoスクリプトを使用してシンプルなCSVファイル（`pagelist.csv`）から生成されるため、コンテンツの管理が容易です。
- **市民中心のナビゲーション**: メニューは、市民の一般的なニーズやライフイベントを中心に構成されています。
  - 妊娠・出産
  - 子育て
  - 入学
  - 引越し
  - 結婚・離婚
- **すぐに使えるコンポーネント**: ニュースのお知らせ、サービスメニュー、連絡先情報など、スタイル設定済みのセクションが含まれています。

## 使い方

このプロジェクトを利用する方法は2つあります:

### 1. 静的HTMLの利用

生成されたHTMLファイルを直接利用できます。`static/demo1/`または`static/demo2/`の内容をウェブサーバーにコピーし、カスタマイズしてください。

### 2. データからのページ生成

`demo1`のページは`pagelist.csv`から生成されます。このCSVファイルを変更し、ページを再生成することができます。
